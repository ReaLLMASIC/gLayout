# E3 controlled editing protocol

This is the prospective protocol implemented by the frozen manifest. Each
freeze retains its actual admission evidence and this document.

The matrix contains 24 complete initial programs, three programs from each of
eight target logics, with a seven-group merge sensitivity. Their domains retain
the target E1 s01 anchor, eight development points and sixteen hidden points.
Actual qualification returned 23 S2 anchors and one completed candidate LVS
failure. Thirteen clean but poor programs and that correctness failure have
same-circuit feasible witnesses. Equal-area mirror variants are not counted as
area shortfalls. Distinct filled geometry, full source, references and witness
bindings are reinspected by the freezer.

References, device dimensions, ports, PDK, solver, stimuli, loads and required
analyses are immutable. Components minimize actual recursive GDS bbox area after
feasibility. The two OTAs maximize worst-corner UGB divided by that area after
every original specification passes. Nominal AC alone never establishes S2.

Every search has a four-hour wall limit, 24 structured decisions, eight patch
attempts and eight full configuration checks. The common context is 16,384
tokens including 1,024 output tokens. The earlier 12k proposal admitted all
initial packets but only four complete feedback payloads in its worst case.
The chosen 16k budget fits all 96 initial packets and eight real-feedback stress
payloads without truncation. Stress replay is a capacity measurement, not a new
episode. Actual near-full H100 SFT, DPO, unchanged-reference and bitwise
adapter/optimizer/CPU-and-CUDA-RNG disk restore completed at this context.
Engineering calibration is not formal model training.

The main 24 × A/R/B/C × five-trial comparison fixes F0: each selected point
receives actual generation, full DRC, LVS, exact per-finger intent, positive
physical RC and all required three-corner analyses. A checks only its anchor
per revision and may leave unnecessary budget unspent. R uses frozen
configuration-selection seeds. B uses boundary-first maximin coverage. C uses
the declared visible-margin/parameter-distance rule. Provider sampling seeds
are unavailable and are distinct from the recorded selector seeds.

All methods acquire the original anchor before editing. Every edit invalidates
its prior verification. R/B/C recheck the anchor and all previously exposed
passes and failures before choosing a new point. Historical measurements may
inform the selector but never verify changed source. Selection requires S2 on
all retained checks, then maximizes verified visible coverage, then worst
objective over that same retained set, then takes the earliest revision.
Otherwise the original source is an explicitly unverified fallback.

The C fallback has margin and distance weights one, with probability and
changed-call-coverage weights zero. Current train vectors do not support a
calibrated configuration-dependent failure ensemble or an impact map. Distance
is a coverage heuristic; nearest observed margins are historical priors.
The Boolean original_development_predicate remains an S2 requirement but is
excluded from continuous-margin arithmetic. An actual two-point gateway
control established finite continuous margins and actual selector consumption.
A train-only replay found minimum margin on check six with B and seven with C;
this single-program diagnostic supports no general superiority claim.

Two signal ablations on eight prospectively chosen edit02 tasks disable
distance or margin separately: 80 additional GPT searches. Zero-weight
probability/coverage channels have no identifiable ablation effect. A separate
ten-search C+F3 comparison uses the fixed two OTA edit02 tasks and matched F0
main C trials. F3 has the same full-check/search limits and at most 32 combined
low-fidelity calls: one PEX acquisition and one TT nominal invocation normally
count two. It may defer only newly selected development points. Deferred
predictions are neither observed failures nor verified passes. Anchors and
retained checks always receive full verification. Train/validation calibration
is copied without evaluation refitting; out-of-support nominal values force
full checks. Final post-release evaluation always uses fresh full execution.

P uses the same C selector and eight common tasks, with random and GPT feedback
parameter search, five trials each: 80 searches. Only its complete numeric
parameter file is editable; a frozen renderer reconstructs the full module.
Every initial rendering matches the code task exactly. Bounds preserve the
declared grid and actual PDK minima. Legal failures and renderer/interface costs
are charged. This is ICPI-inspired search, not a reproduction claim.

I has eight separate 25-arrival streams with independent verified libraries,
nearest previous verified warm starts and exact artifact caching. Only the
current configuration and past arrivals enter its policy packet. Its per-arrival
budget equals one shared-code episode; the entire stream does not have the same
total search budget. All cumulative search, cache, verification and storage
costs are reported. A real control verified the first instance and served the
second identical arrival from its own cache with zero new physical calls.

E4 evaluates T0–T4 on the same 24 tasks and C algorithm, three inference trials
in each of three matching slots: 1,080 searches. T1–T4 require twelve actual
trained, validation-selected frozen models. T0 is one common base model; its
three schedule slots are not independently trained models. The actual frozen
methods and matching serving interface must exist before these searches start.

Formal searches seal their selected complete sources and stop. The shared test
oracle opens only after all 1,730 declared shared searches and all twelve models
are sealed, including P, signal and F3 searches. I runs in the deployment phase
with its current-only interface. The 600-slot original-program baseline plan is
frozen before test and measured after release. Regression joins use original
verified S2 passes, with missing and unknown observations separate.

Each physical worker has two CPUs and an actual resource gate. Queue time counts
against search wall time; new work stops below four GiB free storage. Unknown
execution is retained without an automatic retry. Post-release points are
persisted individually; an unknown stops that queue, with remaining points
NOT_RUN. Private raw logs remain recoverable in verified archives. Hidden
per-configuration vectors stay on the backend and only aggregates leave it.

Primary effects are task paired with source-group and seven-group sensitivity
bootstrap intervals when the paired matrix is complete. Missing observations
retain the full declared denominator and identification bounds; they are not
invented failures or confidence intervals. The paper discloses the transparent
rule fallback, dependent source groups, model/provider limits and any unfinished
matrix. Old E1 interface trials remain a separate preserved cohort.
