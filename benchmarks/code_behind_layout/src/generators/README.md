# New development generators

These implementations are engineering development. Their current runs are excluded from formal E1–E5 measurements and from training data. Independent generator ancestry must be assigned in the frozen registry; this directory's file count is not a lineage count.

## Five-transistor OTA core

`five_t_reference.py` specifies an NMOS differential pair, a PMOS mirror load and an NMOS tail source, plus an explicit diode-connected NMOS reference. The external current source drives that reference. The intended interface is `VDD GND IBIAS VP VN VOUT`. Each schematic finger is written explicitly: 12 NMOS and 8 PMOS fingers in the default sizing, representing six transistor groups.

`five_t.py` is a new high-level assembly, independently written from the existing gLayout OTA/composite cells and the public textbook benchmark compiler. It places six MOS groups in a row and explicitly escapes their four terminals into separated vertical tracks and horizontal buses. It calls only `glayout.primitives.fet.nmos`, `pmos`, `via_stack`, gdsfactory geometry and gdstk export. It does not call an existing OTA, differential pair, current mirror, shared benchmark netlist compiler or the other new OTA assembly. The electrical reference is separately specified rather than obtained from the layout's `info['netlist']`.

The standard schematic topology and use of a disclosed external DC servo are established circuit/testbench techniques. The public MIT textbook-sharing repository at revision `1f90e339` was read for schematic/testbench context. Its layout compiler and recorded outcomes were not used by this implementation. Shared MOS/via PCells retain their existing attribution; this assembly does not imply a new primitive invention.

The first tight prelayout run was `phase0_20261018T232406171686Z_custom_ota_schematic`: tt/ss/ff, 2 pF and 5 pF, 1.8 V supply, 1.1 V input common mode, 20 µA reference. All 24 retained OP/AC/transient/DC analyses passed offline complete-analysis validation. The gain was 40.45–40.49 dB and phase margin 87.88–89.48°. These are development observations, not formal measurements or a guarantee across a continuous domain.

Three layout failures were retained: `phase0_20261018T232613234573Z_custom_ota_build`, `...232710443460Z...`, and `...232826899048Z...`. A 0.6 µm local escape shorted close source/drain bars; merely narrowing the escape did not clear a complete via landing; a well-tie LI escape crossed the outer substrate ring. The final implementation uses 0.2 µm local escapes, moves drain via landings above the close source escape, and takes body contacts from the south M1 tie. The intended schematic stayed unchanged.

`phase0_20261018T232943675208Z_custom_ota_build` passes completed full-rule Magic 8.3.685 DRC, unique independent-gold six-pin LVS and positive full RC: 4,064 R, 444 C and 20 MOS fingers. Dependencies include research gLayout revision `ac3cbc7745c495d8eef5013f1fda2eafa1b432f8` and SKY130A `0fe599b2afb6708d281543108caf8310912f54af`.

`phase0_20261018T233016530653Z_custom_ota_schematic --post-rc` completes extracted tt/ss/ff OP/AC/transient/DC at both loads, with all 24 analyses passing explicit completeness/log validation. The locally retained numerical/integrity record is `results/derived/five_t_development_post_rc.json`. The broad diagnostic DC sweep is tracking/common-mode evidence; it does not establish intrinsic output swing or a passing contract at every sampled point. In particular, the slow corner reaches about 11.8 mV tracking error at the broad sweep boundary, despite passing the nominal 1.1 V bias and small-step stability development criteria. The continuous input/output domain and formal limits remain unset.

The scripts `custom_ota_build.py` and `custom_ota_schematic.py` save the actual source, gold, GDS, reports, extraction and numerical data. Full-rule DRC, LVS, positive RC and complete analyses are separate gates. No proposed S2 specification has been frozen here.

## Independently assembled compact Miller OTA

`compact_miller_reference.py` specifies a conventional NMOS input pair, PMOS current mirror load, NMOS common-source second stage with PMOS current source, NMOS/PMOS diode bias references, and one Miller MIM capacitor. Its seven ports are `VDD GND IBIASN IBIASP VP VN VOUT`; the intended capacitor model pins are `stage1 VOUT` (top, bottom in the actual extracted PDK device). The circuit has nine transistor groups: 24 NMOS fingers, 28 PMOS fingers and one MIM. It is a conventional Miller topology, not an additional topology holdout beyond the existing Miller.

`compact_miller.py` independently places the two gain stages and references in two rows. The input source/tail path, local vertical mirror and gain-node spines, direct second-stage output interconnect, separate bias rails, and M4 top-plate gain-node route are explicit topology decisions. It does not call `five_t.py`, the existing Miller/FVF assemblies or the public universal compiler. Its only layout dependencies are common NMOS/PMOS/MIM/via PCells and geometry/export libraries. The first row/bus OTA and this two-stage assembly share frozen low-level APIs, not their whole placement/netlist-to-routing compiler. The new source comparison and dependency records are supporting evidence, not a proof of independent ancestry.

Tight schematic run `phase0_20261018T233620198148Z_custom_ota_miller_schematic` retained the initial 25 µm capacitor failure: the 2 pF phase margin was 58.30–58.62°, below the unchanged 60° development criterion. The real 30 µm capacitor rerun `phase0_20261018T233912260098Z_custom_ota_miller_schematic` passes all three corners at 1/2 pF with complete analyses. This is physical capacitor sizing, not a relaxed criterion.

The first geometry run `phase0_20261018T234058237159Z_custom_ota_miller_build` retained two body-route M2 spacing violations and a MIM pin-order mismatch against the independent gold. The one bounded repair moves those two body risers and routes the gain node to the physical top plate, preserving the gold. Run `phase0_20261018T234425820562Z_custom_ota_miller_build` passes full-rule Magic 8.3.685 DRC, unique seven-pin LVS, and complete positive extraction: 7,577 R and 1,256 C, with 52 MOS fingers and one MIM.

`phase0_20261018T234515034473Z_custom_ota_miller_schematic --post-rc --cap-size 30` completes actual tt/ss/ff OP, 401-point AC, 4 µs transient and five-point DC at both 1 pF and 2 pF. All 24 analyses pass explicit sweep/log integrity checks. Gain is 76.38–79.65 dB; 2 pF phase margin is 62.07–62.37°, and 1 pF is 67.53–67.79°. The actual nominal bias and small-step development criteria pass in all six corner/load combinations. `results/derived/compact_miller_development_post_rc.json` retains the metrics/integrity. The sizing, source, intended reference, GDS, full-rule reports, full RC and all waveforms remain in the corresponding raw runs. This does not freeze a legal family or establish formal S2 coverage.
